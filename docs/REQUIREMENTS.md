# Aaroh — Requirements Traceability Matrix

## 1. Traceable Requirements Breakdown

### Module A: Discover — Career Explorer
- [x] Multidisciplinary catalog covering Engineering, Commerce, Arts/Design, Sciences, Healthcare, Law, Media
- [x] Search by title, summary, or required skill
- [x] Filter by academic field, workstyle, and beginner accessibility
- [x] Detailed career modal with Day-in-the-Life, real work examples, entry pathways, and trade-offs
- [x] Two- and three-career side-by-side comparison modal
- [x] Non-deterministic compatibility scoring with explicit unknowns and limitations
- [x] Verified source citations with retrieved dates

### Module B: Career Trial Mode (Signature Differentiator)
- [x] Interactive micro-work simulations (UX Design audit, Financial margin sensitivity, Full-stack DB optimization, Public policy transit conflict)
- [x] Objective scenario, instructions, decision prompt, and written rationale
- [x] Weighted evaluation criteria with immediate rubric assessment
- [x] Self-reflection questions capturing enjoyment and energy fit
- [x] Seamless bridge to Adaptive Roadmap and Project Studio

### Module C: Skill Intelligence
- [x] 5 transparent evidence states: Not Assessed, Self-Reported, Coursework, Practically Demonstrated, Independently Verified
- [x] Transparent role coverage formula without claiming hiring probability
- [x] Prerequisite dependency tracking across technical, foundational, and applied skills
- [x] Evidence logging modal with title, URL, and personal reflection notes
- [x] Distinction between unassessed skills and low proficiency

### Module D: Adaptive Roadmap
- [x] Personalized milestone tasks generated from target career hypothesis
- [x] Sequenced prerequisites with auto-unlocking logic
- [x] Dynamic capacity adjustment slider (2 to 20 hrs/week)
- [x] One-click College Exam Mode reducing workload to light maintenance (~3 hrs/wk)
- [x] Anti-guilt philosophy: Zero streaks, zero manipulative alerts, easy task deferral
- [x] Deliverable submission with URL verification and completion audit

### Module E: Project Studio & Portfolio
- [x] Production-grade practical project briefs across multiple disciplines
- [x] Problem statement, target users, architectural scope, and testing checklist
- [x] Interactive README template generator with one-click markdown copy
- [x] Opt-in public portfolio sharing (private by default)

### Module I: Context-Aware AI Mentor
- [x] Student-first conversational guide grounded in confirmed user context
- [x] Transparent AI Context Inspector modal revealing exactly what is shared
- [x] Honest advice acknowledging uncertainties with zero salary/placement hallucinations
- [x] Clear conversation history control
